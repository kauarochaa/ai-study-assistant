# Material de demonstração: Cloud Computing

## Conceito
Cloud Computing é o uso de recursos de computação pela internet, como servidores,
armazenamento e aplicações. É possível ajustar os recursos à demanda e pagar
conforme o uso, acompanhando os gastos.

## Modelos de serviço
IaaS fornece infraestrutura, como máquinas virtuais, redes e armazenamento.
O cliente administra o sistema operacional e suas aplicações.
PaaS fornece uma plataforma para desenvolver e executar aplicações. O provedor
gerencia o sistema operacional e parte maior da infraestrutura.
SaaS fornece um software pronto para uso, como e-mail ou um editor de documentos online.

## Formas de implantação
Nuvem pública é oferecida por um provedor para diferentes clientes.
Nuvem privada é dedicada a uma organização. Nuvem híbrida combina ambientes
de nuvem pública e privada.

## Vantagens
Elasticidade permite ampliar ou reduzir recursos conforme a necessidade.
Agilidade permite criar recursos rapidamente. Pagamento conforme o uso reduz
o investimento inicial em infraestrutura, mas exige monitoramento de gastos.

## Microsoft Azure
Azure Virtual Machines oferece máquinas virtuais. Azure Blob Storage armazena
objetos, como arquivos. Azure Resource Manager ajuda a organizar e administrar
recursos por grupos de recursos e modelos de implantação.

## Google Cloud
Compute Engine oferece máquinas virtuais. Cloud Storage armazena objetos em buckets.
Resource Manager organiza recursos em organizações, pastas e projetos.

## Comparação
Azure e Google Cloud oferecem computação, armazenamento e gerenciamento de recursos.
As ferramentas e os nomes dos serviços são diferentes. A escolha depende das
necessidades, dos custos e do conhecimento da equipe.
